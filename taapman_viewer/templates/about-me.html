WHAT DJANGO TAAPMAN IS AND HOW IT WORKS

What is Django Taapman?

Django Taapman is a weather and country-lookup tool. Search any city, country, or place, and the site pulls together live location data — coordinates, population, capital, currency, spoken languages, the national flag — alongside a full 7-day temperature forecast, all in one place.

It's built as a personal project to explore combining external APIs with a Django backend, and to experiment with a more animated, futuristic front-end instead of a standard template layout.

How It Works

01
You search a place
Type in any city, country, or landmark name in the search bar on the homepage.
02
The backend fetches live data
Django queries external geolocation and country-data APIs to gather details about that location.
03
Forecast data is pulled
A weather API returns the next 7 days of temperature data for that exact location.
04
Everything renders instantly
Country details, flag, languages, currencies, and the forecast grid all appear together on the page.
