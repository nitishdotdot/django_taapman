A Bit About My Work

I'm a mobile and backend developer who builds with Flutter on one side and Node.js on the other, treating the interface someone taps and the API underneath as one connected system rather than two separate jobs. Clean architecture shapes how I structure Flutter projects so they stay easy to extend as they grow, while Express and Prisma ORM guide how I design REST APIs against a PostgreSQL database.

Before software, a degree in Electronics & Communication Engineering trained me to reason through systems and debug from first principles — habits that still shape how I approach a codebase today. Right now, most of my time goes into shipping active projects, committing daily on GitHub, and reading deeper into backend architecture patterns alongside cloud fundamentals.

This particular site, Django Taapman, was built entirely on my own using Django — the views, routing, and API wiring are all mine. For the visual polish you're seeing right now, I brought in Claude to help turn that backend work into a cleaner, more animated interface.
